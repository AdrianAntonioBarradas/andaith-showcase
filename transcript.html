Andaith / Behind the project

Demo transcript

Narrated in English by the creator in his own recorded voice. This readable transcript is edited from the narration script. All demo tasks, identities, and event details are fictional.

00:00 — This is Andaith, a personal scheduler I built with Claude Code’s help and use myself.

00:07 — It runs on my home server and connects scheduled blocks with Telegram reminders and check-ins.

00:15 — I wanted to bring my plans and my check-ins into one place. But using it taught me something.

00:24 — Asking for input every time adds friction. Sometimes, a simple reminder is enough.

00:32 — Let me show you with a fictional example. Alex is working on a project called Atlas.

00:40 — First, Alex schedules a block to prepare an example, with a start time and a duration.

00:50 — When the block starts, Andaith sends a reminder. Alex replies with an intention: prepare a minimal example.

01:01 — At the end, Alex records the result. The original plan stays separate from what Alex reports doing.

01:12 — If Alex doesn’t check in, Andaith records that no response was received.

01:20 — That doesn’t mean the activity didn’t happen. It just means there’s no check-in to show.

01:29 — External agents can also prepare digests and send them through Andaith.

01:37 — This fictional event is one example. The agent gathers the information, and Andaith handles the notification.

01:45 — I’m still using Andaith and exploring integrations that make sense for it.

01:51 — If you’d like to try it, or have a similar challenge, send me an email. I’d love to hear what you have in mind.
