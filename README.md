# Andaith — illustrated product demo

A static introduction to a personal scheduler with one current user. The primary audience is people interested in the workflow or exploring a possible trial.

Serve this directory with a static HTTP server to view `index.html`, video and captions. There is no build step, backend, analytics, interest counter, external asset dependency, form submission, or visitor storage. The contact link opens the visitor’s mail application.

The animation illustrates verified behavior with fictional data. It is not a shipping web interface or a live Telegram recording. The English narration is the creator’s own recorded voice.

Technical design and attribution are in `engineering.html`; verification boundaries in `evidence.html`; the accessible transcript in `transcript.html`. No application source, model weights, private harness, or operational data is distributed.
